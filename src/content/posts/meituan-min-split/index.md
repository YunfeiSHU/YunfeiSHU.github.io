## 题目

给定整数 $n\ge 2$，把 $n$ 拆成两个正整数 $x$ 与 $n-x$（$1\le x<n$），求

$$
\min_{1\le x<n}\ \frac{\operatorname{lcm}(x,\,n-x)}{\gcd(x,\,n-x)}
$$

**样例**

```text
输入：15
输出：2
```

（取 $x=5$：$\gcd(5,10)=5$，$\operatorname{lcm}(5,10)=10$，比值为 $2$。）

---

## 原本思路

```go
package main

import "fmt"

func minRatio(n int) int {
    if n%2 == 0 {
        return 1
    }

    res := n - 1
    for x := 1; x <= n/2; x++ {
        if n%x == 0 {
            res = min(res, (n-x)/x)
        }
    }
    return res
}

func main() {
    var t int
    fmt.Scan(&t)

    for i := 0; i < t; i++ {
        var n int
        fmt.Scan(&n)
        fmt.Println(minRatio(n))
    }
}
```

### 为什么这段能给出正确答案

`if n%x == 0` 把循环限定为只检查 $n$ 的**因数**。对每个被检查的 $x$，令 $S=n/x$，则

$$
\frac{n-x}{x}=\frac{n}{x}-1=S-1
$$

$x$ 取遍 $n$ 的所有真因数（$1\le x\le n/2$，即排除了 $x=n$），而 $x\cdot S=n$ 是一一对应，所以 $S$ 同时取遍 $n$ 的所有 $\ge 2$ 的因数。于是

$$
\text{res}=\min_{S\mid n,\ S\ge 2}(S-1)
=\Big(\min\{\,S:S\mid n,\ S\ge2\,\}\Big)-1
$$

这正是"**最小非平凡因数减 1**"：

- **奇数**：最小因数就是最小素因子 $p$，得 $p-1$，最优解 $x=n/p$；
- **偶数**：最小因数是 $2$，得 $1$——所以开头的偶数特判只是提前返回，**删掉照样对**，因为 $x=n/2$ 本身就在循环里；
- **素数**：除 $x=1$ 外没有真因数，得 $n-1$（即 $x=1$）。

而且**循环必然访问到最优的那个 $x$**：奇数时 $p\ge 3$，故 $n/p\le n/3<n/2$，一定落在循环范围内。$n=15$ 的轨迹：

|  $x$ | $(n-x)/x$ | 对应 $S=n/x$ | 说明          |
| ---: | --------: | -----------: | ------------- |
|    1 |        14 |           15 | 初始化值      |
|    3 |         4 |            5 |               |
|    5 |     **2** |        **3** | $S=p$，最优点 |
| 结果 |     **2** |              |               |

> 为什么"只检查因数"不会漏掉更优解？因为由 4.2 的引理（比值 $=ab$，固定 $a+b$ 时乘积在 $a=1$ 处最小），任意最优解都可化到 $x\mid n$ 上。所以这是**无损筛选**，不是碰巧扫到。

### 为什么必然超时

复杂度是 $O(n)$ 每组：循环跑 $\lfloor n/2\rfloor$ 次，每次一次 64 位取模。

代入 $t\le100,\ n\le10^9$：

- 单组最坏 $5\times10^8$ 次迭代，100 组共 $5\times10^{10}$ 次；
- 按每次 2–4 ns（64 位取模并不便宜）估算需要 **100–200 秒**，即使乐观按 1 ns 算也要 50 秒；
- 常规时限 1–2 秒只允许约 $10^8\sim10^9$ 次基本操作，**超时约 50–100 倍**。

更糟的是这些工作几乎全是无效的：$n\le10^9$ 时因数个数最多只有 $1344$ 个（$n=735134400$），即 $99.9997\%$ 的循环都在做无用功。最坏情况是 $n$ 取大素数（如 $999999937$）：$5\times10^8$ 次循环只找到 $x=1$ 一个因数，最后返回 $n-1$。

| 方案                     | 单组迭代（$n=10^9$） |         100 组总量 |  预估耗时 | 结果 |
| ------------------------ | -------------------: | -----------------: | --------: | ---- |
| 枚举全部 $x$（本节代码） |        $5\times10^8$ |   $5\times10^{10}$ | 100–200 s | TLE  |
| 只枚举奇数 $x$（5.1）    |      $2.5\times10^8$ | $2.5\times10^{10}$ |  50–100 s | TLE  |
| 试除找最小素因子（5.2）  |  $\le 3.2\times10^4$ |    $3.2\times10^6$ |  $<10$ ms | AC   |

注意"只枚举奇数"只能把常数减半，**量级不变，仍然超时**；必须换算法，靠常数优化救不回来。

另外，$n\le10^9$ 时 `(n-x)/x` 不会溢出，`int` 也够用，所以这里**纯粹是时间问题，不是溢出问题**。

## 答案解析

$$
\text{ans}=
\begin{cases}
1, & n \text{ 为偶数}\\[4pt]
p-1, & n \text{ 为奇数},\ p=\text{最小素因子}(n)
\end{cases}
$$

- 偶数取 $x=n/2$；
- 奇数取 $x=n/p$，此时 $n-x=n-n/p$；
- 奇数且为素数时 $p=n$，答案 $n-1$（即 $x=1$）。

复杂度 $O(\sqrt n)$ 每组，$O(1)$ 额外空间。

****

## 正确推导

### 换元：把比值化成一个乘积

设

$$
g=\gcd(x,\,n-x),\qquad x=g\,a,\quad n-x=g\,b,\qquad \gcd(a,b)=1
$$

则 $n=g(a+b)$，因此

$$
g\mid n,\qquad a+b=\frac{n}{g}=:S
$$

而

$$
\operatorname{lcm}(x,n-x)=\frac{x\,(n-x)}{\gcd(x,n-x)}=\frac{g^2ab}{g}=g\,ab
$$

所以

$$
\boxed{\ \frac{\operatorname{lcm}(x,n-x)}{\gcd(x,n-x)}=\frac{g\,ab}{g}=a\,b\ }
$$

**这就是关键一步**：比值与 $g$ 无关，只等于两个互质部分 $a,b$ 的乘积。

问题重新表述为：

> 在所有 $S\mid n$（$S=a+b\ge2$）与所有满足 $\gcd(a,b)=1,\ a+b=S$ 的数对中，最小化 $ab$。

### 固定 $S$：最优必是 $a=1$

对固定 $S$，考虑

$$
a\,b=a(S-a)=S a-a^2
$$

在 $a\in[1,\,S/2]$ 上，相邻两项之差为 $S-2a\ge 0$，故关于 $a$ **单调递增**。因此最小值在 $a=1$ 处取得：

$$
\min a\,b = 1\cdot(S-1)=S-1
$$

而且 $\gcd(1,S-1)=1$ **恒成立**——互质约束自动满足，从头到尾都没有起作用。

### 再对 $S$ 取最小：找最小因数

$$
\text{ans}=\min_{S\mid n,\ S\ge2}(S-1)=\Big(\min\{S\ge 2:S\mid n\}\Big)-1
$$

即"$n$ 的最小非平凡因数减去 1"。

- **$n$ 偶数**：最小因数为 $2$，答案 $2-1=1$，取 $x=n/2$；
- **$n$ 奇数**：最小非平凡因数就是**最小素因子 $p$**，答案 $p-1$，取

$$
x=\frac{n}{p},\qquad n-x=n-\frac{n}{p}
$$

- **$n$ 为奇素数**：$p=n$，答案 $n-1$，取 $x=1$。

### 顺带得到的推论

因为 $a=1$ 时 $g=n/S$，所以最优拆分里的 $x=g=n/S$ **一定是 $n$ 的因数**。这解释了附件第一段代码为什么只检查 `n%x == 0`：

$$
\frac{n-x}{x}=\frac{n}{x}-1=S-1
$$

也说明"枚举 $n$ 的因数而非全部 $x$"不是偷懒，而是有严格依据的。

## 正确代码

### 最小素因子，$O(\sqrt n)$ 每组

既然答案只取决于最小非平凡因数，直接找它即可。

从 $3$ 开始按奇数试除，**第一个找到的除数就是最小素因子**（若某个合数先被找到，它的小素因子会更早被找到，矛盾）；循环到 $n/p$ 仍未找到，则 $n$ 为素数。

```go
package main

import "fmt"

// ans = 1 (n 偶) 或 spf(n) - 1 (n 奇)
func minRatio(n int64) int64 {
	if n%2 == 0 {
		return 1 // 取 x = n/2
	}
	// n 为奇数：找最小素因子 p
	for p := int64(3); p <= n/p; p += 2 { // p <= n/p 等价于 p*p <= n，且不会溢出
		if n%p == 0 {
			return p - 1 // 取 x = n/p
		}
	}
	return n - 1 // n 是奇素数，取 x = 1
}

func main() {
	var t int
	fmt.Scan(&t)
	for i := 0; i < t; i++ {
		var n int64
		fmt.Scan(&n)
		fmt.Println(minRatio(n))
	}
}
```

## 复杂度与易错点

| 方案 | 时间 | 空间 | 备注 |
|---|---|---|---|
| 全量枚举 $x$ | $O(n\log n)$ | $O(1)$ | 仅用于对拍 |
| 枚举因数（5.1） | $O(n)$ | $O(1)$ | 正确，适合理解 |
| 最小素因子（5.2） | $O(\sqrt n)$ | $O(1)$ | 正解 |
| 旧文档的 $d$ 枚举 | 上界 $O(n^{3/2})$，且**答案错误** | $O(1)$ | 勿用 |

## 附：gcd 与 lcm 复习

### 一、gcd（最大公约数）

$$
\gcd(a,b)=\gcd(b,\ a\bmod b)=\gcd(a,\ b-a)
$$

$$
g=\gcd(a,b)\ \Longrightarrow\ \gcd\!\left(\frac{a}{g},\ \frac{b}{g}\right)=1
$$

**迭代版实现：推荐**

```go
// gcd 返回 |a| 与 |b| 的最大公约数；gcd(a,0)=|a|，gcd(0,0)=0
func gcd(a, b int64) int64 {
	if a < 0 {
		a = -a
	}
	if b < 0 {
		b = -b
	}
	for b != 0 {
		a, b = b, a%b // 一次辗转：gcd(a,b) = gcd(b, a%b)
	}
	return a
}
```

- 复杂度 $O(\log\min(a,b))$：最坏输入是相邻两项斐波那契数，实际迭代次数不到 100；
- 用取模而不是减法：更相减损术 `gcd(a,b) = gcd(a, b-a)` 每轮只减一点，最坏 $O(\max(a,b))$，别用。

**递归版：**

```go
func gcdRec(a, b int64) int64 {
	if b == 0 {
		return a
	}
	return gcdRec(b, a%b)
}
```

和数学定义一一对应，写起来最短；但 Go 没有尾调用优化，工程代码统一用迭代版。

### 二、lcm（最小公倍数）

由 $\gcd(a,b)\cdot\operatorname{lcm}(a,b)=|a\,b|$ 得

$$
\operatorname{lcm}(a,b)=\frac{|a\,b|}{\gcd(a,b)},
$$

代码必须**先除后乘**：

```go
// lcm 返回 |a|、|b| 的最小公倍数
func lcm(a, b int64) int64 {
	if a == 0 || b == 0 {
		return 0
	}
	return a / gcd(a, b) * b // 关键：先除后乘
}
```

`gcd(a,b) | a` 恒成立，所以 `a/gcd` 是整除、不丢精度，同时把中间量从 $|ab|$ 降到最终答案本身：

| 写法（取 $a=b=4\times10^9$） | 中间量 | 结果 |
| ---------------------------- | -----: | ---: |
| `a * b / gcd(a, b)`          | $1.6\times10^{19}$ | 溢成负数，错 |
| `a / gcd(a, b) * b`          | $4\times10^9$ | $4\times10^9$，对 |

实现注意：

1. **先乘后除**：`a*b` 溢出后再除救不回来，必须 `a/gcd*b`。
2. **32 位 `int`**：$10^{18}$ 级别直接爆，统一 `int64`。
3. **0 的约定**：任一参数为 0 时 `lcm` 返回 0（代码里已特判）。
